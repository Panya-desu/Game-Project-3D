# งานที่ต้องแก้ที่ตัวโมเดลตัวเอก (ส่งต่อให้ Codex)

ไฟล์ต้นฉบับ: `Documents\Codex\2026-10-14\...\outputs\EchoCharacters_OriginalLook_ArmFix_v3\Source\EchoCharacter_Rigged.blend`
ไฟล์ที่เกมใช้: `Assets/EchoCharacters/Models/EchoCharacter.fbx` (ใช้ร่วมกันทั้งตัวเอกและ The Double)

ตอนนี้ฝั่ง Unity ทำวิธีแก้ชั่วคราวไว้แล้ว (ดูหัวข้อท้ายไฟล์) ปัญหาด้านล่างเป็นเรื่องที่ควรแก้ที่ตัวโมเดลจริง ตัวเลขทุกตัววัดจากไฟล์ .blend ด้วยสคริปต์

ข้อห้าม: **ห้ามเปลี่ยนสัดส่วนหัว มือ หรือตัว** เคยลองขยายหัวและย่อมือแล้ว เจ้าของงานไม่เอา

---

## 1. ผิวต้นขาและสะโพกใต้กระโปรงถูกตัดหาย ทำให้เดินแล้วขาดูลอย (สำคัญที่สุด)

- mesh `Body` มีขอบเปิด (boundary) ที่ความสูงประมาณ z = 0.62 m ซึ่งอยู่ห่างจากหัวกระดูก `LeftUpperLeg` / `RightUpperLeg` ไปตามแนวกระดูก 0.2924 m
- ตั้งแต่ข้อสะโพก (z 0.91) ลงมาถึงขอบนี้ไม่มีผิวเลย ช่วงสะโพก/เชิงกรานก็ไม่มี (นับ vertex ที่ความสูงสะโพกได้ 0 จุด)
- ขอบที่ตัดเป็นวงรี กว้าง 0.067 m ด้านหน้า-หลัง และ 0.062 m ด้านข้าง จุดศูนย์กลางเยื้องไปข้างหน้า 0.013 m
- กระโปรงถูกทำมาสำหรับตัวที่ไม่มีต้นขา เลยแนบสะโพก เวลาก้าวขา ต้นขาที่ควรอยู่ใต้กระโปรงจึงหายไปเลย
- **ที่ต้องทำ:**
  - เติมผิวต้นขาและเชิงกรานกลับเข้าไป โดยผูกน้ำหนักกับ Hips / UpperLeg ให้ต่อกับขอบเดิมแบบเนียน
  - ปรับกระโปรงให้มีระยะห่างพอ ไม่ให้ต้นขาทะลุเวลาเดินหรือวิ่ง (ดูข้อ 5 ด้วย)

## 2. สีผิวขาไม่เข้ากับแขนและหน้า

- ค่าเฉลี่ยสีใน `Skin.png` ตามบริเวณ UV ของแต่ละส่วน:
  - ขา (ส่วนที่ต่ำกว่า 0.62 m): (253, 209, 185)
  - แขน: (253, 214, 191)
- เข่าระบายสีชมพูเข้มไว้ด้วย ในเกมขาเลยดูส้ม/ชมพูกว่าส่วนอื่น
- **ที่ต้องทำ:** ปรับโทนผิวขาในเท็กซ์เจอร์ให้เท่ากับแขน และลดสีชมพูที่เข่าลง

## 3. Normal ของลูกตาหันเข้าในหัว

- mesh `Eyes` หันด้านหลังเข้าหากล้อง ถ้าเรนเดอร์แบบด้านเดียว ลูกตาจะหายหรือกลายเป็นวงรีสีกรมทึบ
- **ที่ต้องทำ:** Flip normals ของ `Eyes` ให้หันออก

## 4. ปกคอเสื้อเป็นแผ่นบางด้านเดียว

- ส่วนที่พับของปกคอ (mesh `Shirt`) เห็นด้านหลังของแผ่นได้ จึงต้องเรนเดอร์สองด้าน
- **ที่ต้องทำ:** ใส่ความหนาให้ปกคอ (Solidify) หรือทำให้เป็นสองด้านจริง
- `Shirt.png` มีแสงเงาสีฟ้าระบายไว้ในเท็กซ์เจอร์ พอใช้กับ toon shader แล้วเงาซ้อนกัน ถ้าเป็นไปได้ให้ใช้สีพื้นขาวเรียบ

## 5. กระโปรงให้พลิ้วแบบ Genshin

- ตอนนี้มีกระดูกกระโปรงแค่ 4 ชิ้น (SkirtFrontLeft / SkirtBackLeft / SkirtFrontRight / SkirtBackRight) ชิ้นละ 0.307 m ห้อยจาก Hips
- กระโปรงส่วนใหญ่ผูกกับ Hips: ผลรวมน้ำหนัก Hips = 808 ส่วนกระดูกกระโปรงทั้ง 4 ชิ้นรวมกันราว 600 การแกว่งเลยหยาบ
- **ที่ต้องทำ:**
  - ทำโซ่กระดูกรอบกระโปรงประมาณ 8 แนว แนวละ 2–3 ข้อ แล้วผูกน้ำหนักให้ชายกระโปรงตามโซ่
  - ตั้งชื่อกระดูกขึ้นต้นด้วย `Skirt` เพื่อให้สคริปต์ `SkirtSpring` ฝั่ง Unity หาเจอ (ตอนนี้สคริปต์รองรับกระดูกเดี่ยว ถ้าเป็นโซ่ต้องขยายสคริปต์ให้ทำงานต่อข้อ)

## 6. ผมไม่มีกระดูก

- ผม (`Hair`) ผูกกับ Head ทั้งหมด จึงทำฟิสิกส์ผมจริงไม่ได้ ตอนนี้ใช้การโยกแบบ shader แทน (ดูท้ายไฟล์)
- **ที่ต้องทำ:**
  - เพิ่มโซ่กระดูกผม เช่น หน้าม้า ข้างซ้าย/ขวา และด้านหลัง แนวละ 2–3 ข้อ
  - ถ้าทำได้ ใส่โซ่สั้นๆ ให้โบว์ (`Ribbon`) และต่างหู (`Earrings`) ด้วย

## ข้อบังคับตอน export FBX (ถ้าไม่ตรง Avatar ใน Unity จะพัง ตัวละครหายทั้งเกม)

เคยพลาดมาแล้วครั้งหนึ่ง: Unity ขึ้น "Avatar Rig Configuration mis-match" ขาคลาดไป 43 ซม.

- ตอน export ให้ armature อยู่ในท่า action `A_TPose` เฟรมแรก ไม่ใช่ Idle
- ตั้งค่า export:
  - `apply_unit_scale=True`
  - `apply_scale_options='FBX_SCALE_UNITS'` (ไฟล์เดิมมี UnitScaleFactor = 100 และ scale ของโหนด = 1)
  - `axis_forward='-Z'`, `axis_up='Y'`
  - `add_leaf_bones=False`
  - `primary_bone_axis='Y'`, `secondary_bone_axis='X'`, `armature_nodetype='NULL'`
  - `bake_anim=True`, `bake_anim_use_all_actions=True`, `bake_anim_use_nla_strips=False`, `bake_anim_force_startend_keying=True`
- ชื่อ object, ชื่อกระดูกเดิม และชื่อ take (`EchoRig|EchoRig|Idle` ฯลฯ) ต้องคงเดิม
- ใช้สคริปต์ที่มีอยู่ได้เลย:
  - `UnityProjects\_work\blend_export.py`: export และเทียบชื่อกับ rest pose ของไฟล์เดิม
  - `UnityProjects\_work\fbx_dump.py`: อ่านค่าดิบใน FBX เทียบ Lcl Translation/Rotation/Scaling และ GlobalSettings
  - ทั้งสองไฟล์ต้องรายงานว่าไม่มี DIFF ยกเว้นกระดูกที่เพิ่มใหม่
- ถ้าเพิ่มกระดูก ให้รัน `Tools > Echo Characters > Rebuild Character Assets` เพื่อสร้าง Avatar ใหม่ แล้วตรวจว่า import ไม่มี Rig Error
- ไฟล์ .meta ของ FBX ตอนนี้เปิด `isReadable: 1` ไว้ (สคริปต์ ThighFill อ่าน mesh) ให้คงไว้

- ชุดนักเรียนตายตัว: เสื้อขาว กระโปรงน้ำเงินกรม ถุงเท้าขาว รองเท้าดำ (โบว์เปลี่ยนได้)
- ผม: ดำอมน้ำเงิน โคน (24,26,42) ปลาย (64,80,128) — เงาผม (0.62,0.66,0.92) ไฮไลต์ (0.72,0.8,1.0) เส้นขอบ (0.04,0.05,0.11)
- ตา: ม่วงน้ำเงิน (hue 248) · โบว์: แดงเข้ม (hue 350) · แว่นและต่างหู: เงิน (214,218,228) · รองเท้า: ดำ

- สคริปต์ลงสี: `UnityProjects\_work\palettes.py` (อ่านเท็กซ์เจอร์ต้นฉบับจากแพ็กเกจ แล้วลงสีชุด U1) ถ้ามีโมเดลหรือผมใหม่ ให้ส่งเท็กซ์เจอร์ต้นฉบับมา แล้วฝั่งเกมจะรันสคริปต์นี้ซ้ำ
